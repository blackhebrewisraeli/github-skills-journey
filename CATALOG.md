## How I update this file

When I finish a course:

1. Change its row to **Finished** and add the `skills-*` link.
2. Recalculate Finished / In progress / Not started. Active catalog should still equal those three counts.
3. Mirror the new counts on [README.md](README.md).
4. Move a short knowledge line into [KNOWLEDGE.md](KNOWLEDGE.md).
5. Remove it from the leftover list in [ROADMAP.md](ROADMAP.md).

When GitHub publishes a new template, add a **Not started** row here before it appears anywhere else.
